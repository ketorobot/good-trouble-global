PERSONAL PRODUCTIVITY TOOL

Alex Daily Email Check

This private tool helps its owner review messages from separately authorized Google email accounts and identify messages that need attention. It runs on the owner's Windows computer and provides email access to Codex for scheduled summaries and owner-directed drafting and sending.

This page describes the tool. It does not provide a public sign-in, mailbox access, or access to the owner's computer. The tool is for its owner's personal use and is not offered to the public.

Privacy and Google user data

Privacy and Google user data

Updated September 15, 2026.

Access and purpose

The tool requests Google's Gmail read-only permission and, when separately authorized by the owner, permission to manage drafts and send email. It uses account identity, message headers, message text, conversation context, labels, and timestamps to find relevant messages and prepare summaries for the owner. The local connection verifies each authorized account before reading messages or performing a requested write.

Processing and sharing

Google provides authorized mailbox data to the local tool over HTTPS. Relevant email content is provided to OpenAI through Codex to generate the requested summaries and may be retained in task history according to the owner's OpenAI account settings and the applicable OpenAI terms and privacy policy. Email data is not published on this website. This tool does not sell email data, use it for advertising, or share it with other recipients except when the owner directs an email to them.

Local storage and security

Google authorization tokens are stored locally by the Google Workspace CLI with encryption backed by Windows Credential Manager. Desktop client configuration files are restricted to the owner's Windows account and the system. The tool may save local check timestamps, message identifiers, and summaries to prevent duplicate reports and support follow-up. It does not need the owner to provide a Google password to the tool.

Limits and control

The connection exposes reading and, for accounts with write permission, draft creation, draft updates, and sending. Drafts and sent messages are stored in the selected Gmail account. Sending is performed only for communications directed by the owner; the daily check alone does not authorize sending. The connection does not expose mailbox deletion, archiving, or marking received messages as read. The owner can pause the scheduled check, revoke the app's access through Google Account settings, remove locally stored authorization and report files, and delete associated Codex task history using OpenAI's controls. Revoking Google access stops future API access; it does not automatically delete previously saved summaries or task history.

Google Limited Use

The tool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. The local tool uses Google data for the owner's requested email-review workflow. It does not train models or create training datasets.
